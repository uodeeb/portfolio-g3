# Portfolio Website

## Project Description:
My portfolio website is a simple one-page website that showcases my skills, projects, and contact information.
It is built using HTML, CSS, and JavaScript.

## Project Features:
- Responsive design for mobile and desktop devices
- Interactive navigation menu
- Contact form with validation
- Animated scroll effect
- Contact information displayed in a footer

## Technology Used:
- HTML
- CSS
- JavaScript
